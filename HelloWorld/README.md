# Adventure Game 

This project is a text-based adventure in which you see if you can escape the forest alive or if you will succumb to the elements of the wild.

## Instructions for Build and Use

Steps to build, run, and / or use the software:

1. Click on the Terminal tab in the upper right hand corner of vs code.
2. Then, select New Terminal
3. Finally, Press Run and the program will begin.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* First thing first, you will need to have vs code installed.
* Next, you need to download the python extension on vs code.
